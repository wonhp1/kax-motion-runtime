# 소리 만들기·마스터

규칙(무엇을 지키나)은 `references/rules.md` — 음색·위계 A5, 잰 조건 E2, 바탕·덕킹·마스터 R2, 등급 순서와 사건 프레임 R12, 렌더 사건에 맞추기 D4. 여기는 만드는 법이다. 소리를 영상에 입히는 함정은 `references/render.md` 4장.

- 음악과 효과음은 **코드로 합성하거나 사용자가 준 파일만** 쓴다. 출처나 라이선스를 모르는 음원, 가사 있는 유행곡은 쓰지 않는다.
- 합성은 시드를 고정한다(같은 시드 = 같은 소리). numpy(48kHz) 또는 WebAudio `OfflineAudioContext`로 파일을 만든다. 렌더 중에 소리를 만들지 않는다.
- 파일 자리(작업 폴더): `audio/sfx/`(효과음 하나씩), `audio/events.json`(효과음 계획), `audio/mix_raw.wav`(섞은 것 — 봉우리 −3 dBFS 안팎, 5장), `audio/mix.wav`(마스터 뒤).

## 1. 사건과 등급 — `audio/events.json`
효과음 하나 = 화면 사건 하나다. 계획 파일 꼴(측정 도구·마스터가 같이 읽는다):

```json
{"fps": "30000/1001",
 "events": [
  {"frame": 12,  "type": "tick",  "tier": "first",     "what": "첫 글자 착지",  "visual": "land"},
  {"frame": 96,  "type": "click", "tier": "normal",    "what": "보내기 누름",   "visual": "land"},
  {"frame": 150, "type": "whoosh","tier": "signature", "what": "줌 통과 시작"},
  {"frame": 163, "type": "tick",  "tier": "detail",    "what": "작은 반짝"}]}
```
- `frame`(또는 `time_s`) — 렌더에서 잰 사건 프레임(D4). `tier` — `signature`·`first`·`normal`·`detail` 중 하나. 영상 전체에 signature 하나, first 하나.
- `visual: "land"` — 착지·멈춤 사건이라는 표시. `--sync`가 화면이 멈추는 프레임까지 같이 대 본다.
- 부품을 쓰면 사건 프레임을 부품에서 받는다:
  ```js
  const evts = KC.retier(KC.events([title, card, wipe]), { first: "word_land", signature: "zoom" });
  // evts[i] = {f, type, tier, onset, land, hint, id} — tier는 normal·detail, first·signature는 retier가 하나씩 고름
  ```
  - **페이지에서 뽑기**: `python3 -I <이 스킬>/scripts/events_dump.py --plan audio/events_draft.json --first <type> --signature <type>`(작업 폴더에서).
    `index.html`을 헤드리스 크롬으로 열어(파일은 고치지 않음) 페이지가 만든 부품(`KC.make`) 전부의 `events()`를 `audio/parts_events.json`에 쓰고,
    `KC.retier`를 거친 계획 초안을 `--plan` 파일에 쓴다. toHF 목록에 안 넣고 `under`에서 직접 그린 부품도 잡힌다(만들고 안 쓴 부품은 `--only`로 뺌).
    초안의 `frame` = 부품 사건 `f`(`visual: "land"` = 앉음·누름 사건). 소리 종류·크기를 정하고 렌더에서 잰 프레임과 대 본 뒤 `audio/events.json`으로 옮긴다
    (있는 파일은 `--force` 없이 덮지 않음). 부품 밖 사건(kx `bw.events()` 등)은 `--expr "bw.events()"`로 함께 받는다. 부품 입력·차례를 바꿀 때마다 다시 뽑는다.
  - 휙·쓸림 소리는 `onset`(움직임 시작), 착지·누름·딸깍은 `land`(닿음·멈춤)에 둔다(R12).
  - kx 엔진 낱말 튐은 `bw.landFrames()`·`bw.events()`(`engine/kx/README.md`).
- **소리의 머리(가장 먼저 크게 들리는 자리)를 화면 사건 프레임에 둔다.** 측정 도구가 사건 프레임 둘레만 잰다: `--sfx`는 [사건 −30ms, +90ms] 창의 크기를 바로 앞 200ms와 견주고, `--sync`는 사건 ±45ms 안에서 소리가 솟는 자리를 화면 변화와 맞춘다.
  - **휙은 앞이 크게** 만든다: 어택 3~20ms로 바로 크게 시작해(시작 프레임에 이미 봉우리의 60% 이상) 봉우리를 시작 90ms 안에 두고, 꼬리를 움직임 길이만큼 끈다. 사건 프레임 = 움직임이 보이기 시작한 프레임(`onset`, R12). 공개 예시의 휙이 모두 이 꼴이다(봉우리 70~90ms, 어택 3~22ms).
  - 컷 앞 가속 퇴장: 휙의 머리를 **퇴장이 눈에 띄게 움직이기 시작한 프레임**에 두고, 꼬리가 컷에서 끝나게 길이를 맞춘다(퇴장 6~8프레임이면 휙 200~270ms). 컷 자체를 세게 들리게 하려면 컷 프레임에 짧은 톡·쿵을 사건 하나로 더한다.
  - **뒤가 커지는 소리**(부풀다 컷에서 끊기는 라이저·역재생 휙)는 사건으로 세지 않는다 — 머리가 작아 `--sfx` ③(+8dB)과 `--sync`에서 떨어지고, 봉우리에 사건을 두면 앞 200ms가 이미 커서 바탕 대비가 낮게 나온다. 쓰려면 바탕 쪽 소리로 −6dB 이상 낮춰 깔고, 끝 프레임에 앞이 큰 짧은 소리(딸깍·톡·쿵)를 붙여 그것을 사건으로 적는다.
  - 감속으로 들어와 닿는 움직임에는 쿵·톡을 닿는 프레임에 둔다.
  - 누름은 가장 눌린 프레임에 딸깍을 둔다.
- 일정 간격 틱으로 목록을 덮지 않는다. 실제 줄 넘김마다 놓는다(D4).
- 같은 종류가 연달아 나오면 시드를 고정해 음높이 ±8%(또는 ±1~2반음), 세기 ±2dB씩 흔든다. 기계 반복처럼 들리지 않게.
- 화면에 이유가 없는 소리는 넣지 않는다.

## 2. 크기 위계 정하기
- 믹스에서 처음 놓는 크기(A5): signature·first −6dB, normal −12dB, detail −18dB. 같은 짧은 잔향 하나에 모두 보낸다.
- 큰 착지 바로 뒤(1~2프레임)의 작은 튐은 앞 소리 꼬리에 묻혀 크게 재진다. 겹치면 detail을 더 낮추거나 시각을 띄운다.
- 잰 값으로 확인한다: `python3 -I <이 스킬>/critic/tools/measure_motion.py out/final.mp4 --out review/measure --sfx --events audio/events.json`
  - `n_timbres` ≥ 4, 위계(signature·first − normal) ≥ +4dB, `over_bed_db` ≥ 8인 사건 80% 이상, `tier_order`의 `ok`(detail ≤ normal − 2dB). 넷을 함께 센 상한 후보는 `q8_v06.cap`.
  - 8dB를 못 넘은 사건은 `masked_by`로 음악에 묻혔는지 앞 효과음에 묻혔는지 본다. 겹친 사건 때문이면 `louder_details`·`alone`을 본다.
- 싱크: 같은 계획으로 `--sync` → `audio_on_visual_within_1frame` ≥ 0.8. 우연 수준 `chance_*`(보통 0.2~0.4)보다 충분히 높아야 근거가 된다.

## 3. 합성 단서
### 예시 `sfx.json` 읽기
`get_example`로 받은 `example/sfx.json`이 효과음 단서다.
- `events[]` — `name`(소리 종류)·`when`(어떤 화면 사건에)·`synth`·`recipe`(합성법)·`gain_db`(믹스 크기)·`variation`. 프레임 번호는 그 예시 기준이다. **새 영상은 같은 종류의 사건에 붙이고, 프레임은 새 영상의 렌더에서 잰다.**
- `synth_recipes` — 종류별 합성법·길이·크기. `music_bed` — 바탕 성격·빠르기·크기 흐름. `mix_rules` — 섞는 규칙(그대로 따른다). `loudness` — 그 예시의 음량(새 영상의 목표는 5장).

### 기본 합성법
예시에 합성법이 없을 때 쓴다. 크기는 처음 놓는 값이고, 위계는 2장으로 맞춘다.

| 소리 | 쓰는 곳 | 합성 | 길이 |
|---|---|---|---|
| 틱 | 타자·칸 첫 글자 착지 | 사인 2.2~3.5kHz + 하이패스(4kHz) 노이즈, 어택 1ms, 지수 감쇠, 피치 −8% 내림. 또는 2~4kHz 노이즈 버스트(τ ≈ 4ms) + 1.2kHz 사인 톡 5ms | 8~35ms |
| 작은 틱 묶음 | 글자 연속 팝(detail) | 틱의 절반 길이·−6dB를 2~3프레임 간격으로 3~5개, 뒤로 갈수록 작게 | 20ms씩 |
| 딸깍 | 버튼 누름 | 낮은 툭(사인 180Hz → 90Hz 30ms) + 높은 딸깍(3.5kHz 노이즈 6ms) | 30ms |
| 톡 두 번 | 칩·단계가 생길 때 | 사인 1.6kHz 15ms + 2.4kHz 10ms, 40ms 간격 두 번 | 60ms |
| 팝 | 바탕색 바뀜·말풍선 | 사인 600Hz → 1.2kHz로 위로 휘는 소리 + 아주 짧은 노이즈 머리 | 40ms |
| 짧은 휙 | 이동·퇴장 | 핑크 노이즈 → 대역 통과 중심 600Hz → 2.5kHz 쓸기, 어택 10~20ms(시작 프레임에 이미 크게)·봉우리 60~80ms·감쇠 120ms. 사건 프레임 = 움직임 시작 | 220ms |
| 내려가는 휙 + 붐 | 틀이 바뀔 때 | 노이즈 대역 통과 2kHz → 600Hz 쓸기 + 저역 붐(60Hz 80ms) | 180ms |
| 올라가는 쓸기 + 반짝 | 생각 중·결과 등장 | 분홍 노이즈 대역 통과 400Hz → 4kHz, 앞 20ms 세게, 끝 페이드 + 8kHz 사인 3개 화음 80ms | 250ms |
| 줌 통과 라이저 | 확대 가속 전환 | 노이즈 대역 통과 300Hz → 6kHz 지수 쓸기 + 사인 라이저 200 → 800Hz, 화면 밖으로 빠지는 프레임에서 뚝 끊음. 뒤가 커지는 소리라 사건이 아니라 바탕 쪽으로 낮춰 깔고, 끊는 프레임에 짧은 톡·쿵을 사건으로(1장) | 600ms |
| 셔터 | 사진 교체 | 노이즈 버스트 2개(25ms 간격), 첫째 고역·둘째 중역 | 12ms씩 |
| 글리치 | 글자 흐트러짐 | 3~8ms마다 음높이가 바뀌는 사각파 조각 + 비트크러시, 끝에 짧은 톡 | 60~120ms |
| 글리치 틱 | 글리프 교체 | 비트크러시된 사각파 1~2kHz 20ms + 노이즈 5ms | 25ms |
| 쿵 | 로고·마무리 | 저음과 짧은 잔향 | — |
| 맺음(선택) | 끝 카드 | 부드러운 패드 화음, 1초 페이드아웃 | 1초 |

- 기본 세 가지는 딸깍(누름)·휙(변형·이동)·쿵(로고·마무리)이다. 그 밖의 소리는 화면에 이유가 있을 때만.
- 끝 카드에는 맺는 소리 하나를 두고(D5) 음악은 줄여 닫는다.

## 4. 바탕 음악·덕킹·박
- **바탕**: 사용자 음악이 없으면 합성한다. 뼈대는 킥(강박)·하이햇(8분음표)·베이스(마디마다 근음)·패드(코드 2~4개 되풀이). 분위기에 맞춰 악기 수를 줄인다. 루프 영상이면 마지막 마디가 첫 마디로 이어지게.
- **크기**: '효과음이 바로 앞 바탕보다 +8dB 이상인 사건 80% 이상'이 되게 둔다. 마스터 뒤 `--sfx`에서 바탕 `bed_dbfs` 중앙값 −20~−28 dBFS, 일반 사건보다 11~16dB 아래가 맞은 값이다(R2).
- **덕킹**: 사건마다 0.25~0.3초 동안 바탕 이득을 −6~−10dB로 눌렀다가 되돌린다. 음악이 촘촘하면 −10 쪽. 바탕 줄에만 곱하고 효과음 줄은 그대로 둔다.
- **내레이션**이 있으면 음악을 내레이션 아래로 18~20dB 낮춘다.
- **박**: 빠르기(BPM)를 먼저 정하고 칸·낱말 등장 간격을 한 박으로 둔다 — 간격(프레임) = fps × 60 ÷ BPM(예: 24fps·152BPM → 9.47프레임, kx `KXP.cellStarts`). 장면 전환 시작은 마디 첫 박, 누름 바닥은 박 또는 반박에. 사용자가 준 곡이면 박을 재서 쓰고, 표에 적은 빠르기와 다르면 잰 값을 따른다.
- 박 자료를 쓰면 렌더 중에 파일로 읽지 않고 HTML 안에 넣는다(`references/render.md` 1장).

## 5. 마스터 — `scripts/master.py`
```bash
python3 -I <이 스킬>/scripts/master.py audio/mix_raw.wav audio/mix.wav --events audio/events.json --report review/master.json
```
- **마스터 전 믹스(`audio/mix_raw.wav`)는 표본 봉우리를 −3 dBFS 안팎으로 두고 쓴다.** 섞은 뒤 봉우리가 −3 dBFS보다 크면 믹스 전체에 같은 이득 하나를 곱해 −3 dBFS로 내린 뒤 쓴다(바탕·효과음 크기 비는 그대로 — 전체 음량은 마스터가 맞춘다). 16비트 WAV는 0 dBFS 위가 잘리고, 잘린 소리는 마스터가 되돌리지 못한다 — `master.py`가 잘린 흔적을 찾으면 경고(끝 코드 2)한다.
- 하는 일: 믹스 전체에 **같은 이득 하나**를 곱하고, 트루피크가 넘치는 순간만 리미터(4배 오버샘플 피크, 미리보기 2ms·되돌림 80ms)로 누른다. 이득은 목표 음량이 될 때까지 되풀이해 찾는다. 바탕과 효과음의 크기 비가 그대로 남는다.
- 목표 −14 LUFS(±0.15), 천장 −2 dBTP. 마지막에 AAC 192k로 굳혀 트루피크를 재고, −1.2 dBTP를 넘으면 천장을 그만큼 낮춰 다시 한다(렌더가 소리를 낮추지 않게).
- 인자: `--target`(LUFS, 기본 −14), `--tol`(0.15), `--ceiling`(dBTP, 기본 −2.0), `--release`(초, 0.08), `--events`(계획 — 사건별 눌림·위계 보고), `--fps`(계획에 fps가 없을 때, 기본 24), `--report`(JSON), `--no-aac-check`.
- `--events`를 주면 사건마다 리미터가 누른 양과 등급별 위계(signature·first − normal)를 '이득만 곱했을 때'와 '결과'로 나란히 보이고, 등급별(detail / normal / first·signature) 사건 크기 중앙값을 한 줄 더 찍는다.
- **경고(끝 코드 2)가 나오면 마스터가 아니라 믹스를 고쳐 다시 돌린다.**

  | 경고 | 고칠 것(믹스에서) |
  |---|---|
  | 마스터 전 믹스가 0 dBFS에서 잘림 | 섞은 뒤 전체에 같은 이득을 곱해 표본 봉우리를 −3 dBFS로 내리고 다시 쓴다 |
  | 리미터가 위계를 +4dB 아래로 누름 | 그 큰 사건을 1~3dB 줄인다 |
  | 리미터 경고 끝에 '원인 후보: 봉우리가 20ms RMS보다 12dB 넘게 높은 사건'(짧은 소리 봉우리) | 4~30ms짜리 짧은 소리(틱·딸깍·톡)를 `sfx.json` `gain_db`(20ms RMS 기준)로 맞추면 소리가 창보다 짧아 봉우리가 RMS보다 13dB 넘게 높다 → 리미터가 그 봉우리부터 눌러 '5% 넘게 누름'·위계 눌림이 함께 난다. 그 효과음만 봉우리를 둥글게 한다: `y = tanh(k·x)/tanh(k)`(k 2~4)처럼 부드럽게 자르거나 어택을 1→3ms로 늘려 봉우리 − RMS ≤ 10dB(`--report` `events[].crest_db`)로 만든 뒤 RMS 크기를 다시 맞춰 섞는다. 믹스 전체에 자르기를 걸지 않는다(바탕까지 일그러짐) |
  | 리미터가 전체 시간의 5% 넘게 1dB 넘게 누름 | 마스터 전 믹스를 목표 가까이 키우고(바탕·일반 사건을 올림) 가장 큰 사건만 봉우리로 남긴다 |
  | 등급 순서 뒤집힘·차가 모자람(detail이 normal − 2dB보다 큼) | 리미터 전부터 그랬으면 detail을 내리거나 normal을 올린다. 리미터가 뒤집었으면 큰 normal 사건을 줄인다 |
  | 목표 음량·AAC 트루피크를 못 맞춤 | 가장 큰 타격을 낮추고 다시 섞는다 |

  위계가 0.5dB 넘게 줄었지만 +4dB 위면 '참고'로만 알린다.
