# KAX Motion Runtime

코드 실행이 가능한 AI 환경에서 KAX Motion MCP와 함께 쓰는 공식 공개 실행 코드입니다. AI가 실행 환경을 자동으로 준비하므로 사용자가 ZIP을 내려받거나 전역 스킬 폴더에 설치할 필요가 없습니다.

## 시작하기

1. [KAX 홈페이지](https://kax.ai.kr/account)에서 가입 동의와 연결 키 발급을 완료합니다. 서비스 공개 여부와 계정 접근 권한에 따라 이용할 수 있습니다.
2. **키 포함 연결 프롬프트**를 복사해 신뢰하는 개인 코딩 AI에 붙여 넣습니다.
3. AI가 `get_status`와 `kax_prepare_runtime`을 호출하고 공식 설치기와 실행 패키지의 SHA-256을 확인합니다.
4. AI가 캐시에 실행 코드를 준비하고 `instructionsPath`의 제작 규칙을 읽은 뒤 영상을 만듭니다. 렌더링은 사용자 작업 환경에서 합니다.

원격 MCP와 인증 헤더, 로컬 파일 쓰기·명령 실행을 지원하는 AI 클라이언트가 필요합니다. 웹 채팅만 제공하는 환경에서는 실행할 수 없습니다. 특정 AI 제품 전체의 호환성을 보장하지 않습니다.

## 공개된 것

- `kax-motion/`: 공식 0.6.7 공개 실행 코드와 제작 안내, 엔진, 서체, 외부 라이브러리
- `installer/bootstrap.py`: 검증 설치·캐시 재사용 도우미
- `runtime.json`: 공식 실행 아카이브의 버전·크기·SHA-256
- `runtime-files.json`: 공개 실행 파일 109개의 SHA-256

릴리스의 실행 아카이브는 AI가 자동으로 받아 검증·해제하는 배포 형식입니다. 수동 ZIP 설치를 요청하지 않습니다. 원본 파일은 검증된 공개 배포본 그대로이며, 홈페이지와 비공개 제작 저장소의 소스는 포함하지 않습니다.
